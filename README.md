# Dawn to Dusk

[简体中文](README.md) · [English](README.en.md)

**Dawn to Dusk**（中文名「朝夕」）是一款面向 macOS 的原生日程与待办应用。它把有日期的安排放在「日程」，把尚未安排日期的事项放在「清单」，并用桌面浮窗、时间提醒和本地数据保存帮助用户查看当天安排。

支持简体中文和 English，可在「设置 → 外观 → 语言 / Language」即时切换。日程名称和备注保留你输入的内容。

## 功能

- 日程与跨天保留的待办清单
- 在日程页点「编辑日程」，统一新增、删除和调整安排；点「保存修改」一起生效，取消可放弃整次编辑。已完成的单次日程从编辑列表隐藏，历史记录保留
- 每天、工作日或每周重复；支持同一条日程按星期设置不同时间，例如周一 09:00、周二至周五 10:00
- 临时变动先选「预览日期」，再点「仅改 YYYY-MM-DD 这一次」；只改所选日期，后续仍按每周规律执行。也可从日程事项进入「仅这一次」编辑
- 小时和分钟可直接输入，也可点数字右侧的时钟图标打开双列滚轮。范围为 00–23 时、00–59 分；删空按 00 处理，输入时不打断，点「完成」或回车后再排序
- 时长可直接输入 0–1440 分钟，也可一键选「不设、15 分钟、30 分钟、1 小时」；清空或输入 0 表示不设时长。每条编辑卡片右下角直接显示持续时间，折叠详情后仍可见
- 在「设置 → 外观 → 日程显示」开关相邻安排和跨夜间隔；编辑页的间隔预览独立开关
- 「稍后提醒」与「推迟这次安排」分开处理
- 系统本地通知、菜单栏入口、小窗、置顶和多种外观；小窗可独立切换最近安排与固定事项
- 本地 JSON 存储、备份导出与恢复
- 本机捕获和只读查询命令行接口
- 可选飞书主日历只读同步；不会向飞书写入

## 系统要求

- macOS 15 或更新版本
- Apple Silicon
- Xcode Command Line Tools

## 构建和运行

```sh
./scripts/build.sh
open build/朝夕.app
```

运行检查脚本：

```sh
./scripts/test.sh
```

应用数据保存在 `~/Library/Application Support/Chaoxi/agenda.json`。日程核心功能使用本机数据；飞书同步需要另行安装并登录 `lark-cli`，当前查找路径为 `~/bin/lark-cli`。飞书数据只读主日历，并按应用设置定期刷新。

仓库只包含源码、说明和合成测试数据，不包含个人日程、清单、完成记录、备份或账号凭据。本机数据、导出备份和截图应保留在仓库之外。

Hermes 捕获辅助脚本位于 `Integrations/Hermes/chaoxi-capture/scripts/capture.py`，通过标准输入接收 JSON，并调用 `~/Applications/朝夕.app` 的本机命令行入口。Clawd 桌面宠物桥接仍是本地定制内容，不包含在这个公开仓库中。
